### US-B1.5 — the create dialog offers only the selected project's lists

         [data-testid="task-form-priority"] after switching
         [data-testid="task-form-project"].

Project selected: Personal
  statuses:   ["Project default", "To Do", "In Progress", "Done"]
  priorities: ["Project default", "Medium", "High", "Someday"]

Project selected: Marketing site
  statuses:   ["Project default", "Backlog", "Blocked", "In Progress", "Done"]
  priorities: ["Project default", "Low", "Medium", "High"]

  priorities: ["Project default", "Low"]

No project's list ever leaks into another's, and the "Project default"
sentinel is what makes status/priority optional inputs (US-B1.1).
